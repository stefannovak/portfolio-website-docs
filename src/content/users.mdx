# Users

## Fetching user info

Returns information about the current authenticated user.

```http
GET /users/me
```

### Parameters

#### Authorization (header, required)

Bearer authentication header of the form `Bearer <token>`, where `<token>` is your auth token.

### Response Fields

#### subscriptionPlan

Available options: `FREE`, `PRO`, `BUSINESS`

#### id

Unique identifier for the user.

#### firstName

User's first name.

#### lastName

User's last name.

#### fullName

User's full name (concatenation of first and last name).

#### email

User's email address.

#### avatarUrl

URL to the user's profile avatar image.

#### organizationId

ID of the organization the user belongs to.

#### isDeleted

Boolean indicating if the user account has been deleted.

#### hasTwoFactorEnabled

Boolean indicating if two-factor authentication is enabled.

#### createdAt

Timestamp when the user account was created (ISO 8601 format).

#### updatedAt

Timestamp when the user account was last updated (ISO 8601 format).
